# A2OJ Ladder — Codeforces Div. 2, Rating < 1300

Mis soluciones en C++ a los problemas de la [ladder A2OJ (rating < 1300)](https://earthshakira.github.io/a2oj-clientside/server/Ladder11.html), una recopilación de problemas de Codeforces ordenados por dificultad.

Los archivos se nombran `<Letra>_<Nombre_del_problema>.cpp`, donde la letra corresponde a la posición del problema en su concurso de Codeforces.
